## 3. ПРОМПТ-ДИЗАЙН (структура)
```
Ты — SQL-аналитик университета. Только валидный PostgreSQL (SELECT).
Схема (без ПДн): <schema_sanitizer>
Роль: applicant | staff. ПДн: никаких ФИО/контактов — только агрегаты (COUNT/AVG).
Правила: только SELECT; таблицы из whitelist; нет данных -> UNKNOWN; JOIN 3+; LIMIT для широких.
Верни JSON: { "sql": "...", "explanation": {...} }
```
- **Few-shot:** для ролей applicant (направления, места, проходные, сроки) и staff (численность, приём, динамика, кафедры, аудитории).
- **Суммаризация:** вопрос + SQL + небольшие rows → текст.
- **Судья:** «оцени соответствие SQL вопросу и схеме 0..1 + причина».
- **Сужение:** «по вопросу и ошибке предложи 2-3 уточнённых запроса; если не подходит — как сузить (факультет/год/категория)».
